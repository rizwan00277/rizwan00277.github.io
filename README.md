# Muhammad Rizwan — Academic Website

Source for [rizwan00277.github.io](https://rizwan00277.github.io/), built with the
[al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and deployed by GitHub Actions
to the `gh-pages` branch.

## Where to edit

| What | File |
| --- | --- |
| Bio, photo, subtitle | `_pages/about.md`, `assets/img/prof_pic.png` |
| News items | `_news/*.md` (one file per item) |
| Publications | `_bibliography/papers.bib` (`selected = {true}` shows it on the home page) |
| Projects | `_projects/*.md`, images in `assets/img/projects/` |
| CV page | `_data/cv.yml`; PDF in `assets/pdf/Muhammad_Rizwan_CV.pdf` |
| Social links | `_data/socials.yml` |
| Site settings | `_config.yml` |

Push to `main` and the **Deploy site** workflow rebuilds the site in about 3–5 minutes.
